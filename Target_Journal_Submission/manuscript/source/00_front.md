# Missing values in random-convolution time series classification: observed-tap weighting for MiniRocket and a pre-specified evaluation

**Abstract**

Random-convolution classifiers such as MiniRocket are fast and accurate, but they assume complete series, so missing values are usually zero-filled or interpolated first. We analyse how missingness should enter these transforms. Writing MiniRocket's zero-sum kernel response as a contrast of tap-group means gives a native estimator that is unbiased under random missingness. It also shows that interpolation fabricates responses inside long gaps. We propose MissRocket, which keeps interpolated responses but weights each response's contribution to pooling by the fraction of its taps that were actually observed. In a pre-specified evaluation on {{N_CONF}} UCR datasets with three missingness mechanisms at three rates, MissRocket improved on MiniRocket with interpolation by {{Q:table_pooled_statistics;baseline=MiniRocket + linear interp.;col=mean_diff;fmt=pp}} percentage points on average (Holm-adjusted Wilcoxon p {{Q:table_pooled_statistics;baseline=MiniRocket + linear interp.;col=p_holm;fmt=p}}). The gain reached {{Q:table_main_statistics;mechanism=block;rate=0.8;baseline=MiniRocket + linear interp.;col=mean_diff;fmt=pp}} points for contiguous gaps and {{Q:table_main_statistics;mechanism=mnar;rate=0.8;baseline=MiniRocket + linear interp.;col=mean_diff;fmt=pp}} points for value-dependent missingness, with no significant difference under random missingness. It was markedly more robust when test data were more incomplete than training data. It matched MultiRocket and Hydra-MultiRocket on average at lower computational cost. However, the native estimator was consistently worse than interpolation. Cross-series k-nearest-neighbour imputation was more accurate on average for contiguous gaps. On sparse clinical records (PhysioNet 2012), GRU-D and gradient boosting outperformed all random-convolution methods. Code and per-run results are released.

Aims and scope
The Journal of King Saud University Computer
and Information Sciences
 is a refereed, international journal that covers all aspects of both foundations of computer and its practical applications. Special emphasis is given to recent trends related to the cutting-edge research within the domain.
The journal publishes original papers in the areas of, but not limited to:
1.     Artificial Intelligence
Fuzzy Systems
Machine Learning
Natural Language Processing
Data Mining
2.     Data Analysis and Representation
Big Data
Bioinformatics
Database Systems
Information Systems
3.     Signal Processing and Computer Vision
Computer Graphics
Computer Vision
Image Processing
Pattern Recognition
Speech Processing
4.     Computer Networks
Cloud Computing
Grid Computing
High Performance Computing
Internet of Things
Mobile Computing
Network Protocols
Social Networks
Wireless and Mobile Networks
Wireless Sensor Networks
5.     Security
Blockchain
Cybersecurity
Data Encryption
Information Security
 Network Security
6.     Computer Engineering
Embedded Systems
Quantum Computing
Robotics
7.     Software Engineering
Software Architecture
Software Verification
Software Reliability
Software Testing
